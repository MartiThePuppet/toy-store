## Выполнено автоматически при создании

Проверки выполнены локально, без публикации. JavaScript проверен движком Node.js 24.20.0, доступным через установленный VS Code (режим ELECTRON_RUN_AS_NODE). Функциональные проверки выполнены в установленном Chrome headless через локальный HTTP-сервер и CDP. Это не заменяет ручную визуальную проверку.

- Синтаксис `assets/js/data.js` и `assets/js/app.js`: успешно (компиляция vm.Script и --check).
- В данных 22 товара и 5 категорий, ID уникальны, файлы иллюстраций существуют.
- Локальный сервер: главная отвечает HTTP 200 и `text/html; charset=utf-8`.
- Проверены оболочки всех 7 HTML: язык ru, title, main; все статические src/href ведут к существующим файлам. Это структурная проверка, не полноценная HTML-валидация.
- Все 5 SVG успешно разобраны как XML; синтаксис Start-Server.ps1 проверен PowerShell Parser.
- Главная сформирована: 5 категорий и 4 товара подборки.
- Повторное добавление одного товара суммирует количество в localStorage.
- Фильтр возраста 3 года показывает 13 подходящих товаров по правилу minAge <= 3.
- Комбинация категории, наличия, цены и сортировки даёт ожидаемый результат (3 набора творчества в диапазоне 800–1500 ₽).
- Неизвестный поисковый запрос показывает пустое состояние и сброс.
- Неизвестный ID показывает сообщение вместо карточки.
- У отсутствующего товара кнопка покупки отключена.
- Восстановление корзины удаляет неизвестный и отсутствующий товары, отрицательное количество; 99 ограничивается до 20.
- Уменьшение количества в корзине работает и сохраняется.
- Пустая форма оформления отмечает три обязательных поля.
- Доставка прибавляет 300 ₽: 19 × 2490 + 300 = 47 610 ₽.
- Успешное оформление показывает итог, очищает корзину; тестовый email не записывается в localStorage.
